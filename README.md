# Reality APP · Red social

Proyecto **independiente** dentro de realityapp.org.

- URL pública: https://realityapp.org/social
- Repositorio: `douglasvelezv/realityapp-social`
- Despliegue (Hostinger Git): este repo se publica en la carpeta **`public_html/social`**.
- No comparte código con la tienda (`realityapp-web`) ni con el otro proyecto.

## Seguridad
- La configuración real (`config/config.php`) vive fuera del control de versiones y no es accesible por web.
- Copia `config-example/config.sample.php` a `config/config.php` y rellena tus datos.
